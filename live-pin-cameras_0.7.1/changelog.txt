Version: 0.7.1
Date: 2026-09-12
  Bugfixes:
    - Distant machine clicks enter native remote view before opening instead of refusing inspection.
    - Retained native remote controller during inventory interaction; no character-mode reach bypass.
    - Replaced pan binding with Shift+right mouse; duplicate input events no longer toggle panning off.
    - Interior hover-cell transitions no longer cancel camera panning.
  Changes:
    - Empty-hand right click requests robot deconstruction; Shift+right drag is reserved for panning.

---------------------------------------------------------------------------------------------------
Version: 0.7.0
Date: 2026-09-05
  Features:
    - Camera manager (Ctrl+Shift+L or click i): names, hide/show, view-only mode, deletion and native remote view.
    - X now hides cameras for later restoration without bookmarks.
    - Added upgrade planners and Ctrl-click two-corner area orders; Shift cancels.
    - Cursor-anchored wheel zoom, screen-bound clamping and configurable per-player camera limits.
  Optimizations:
    - Replaced full-view entity-to-cell rasterization with local on-demand hover queries.
    - Bounded overlay grids to 1024 cells maximum; 600 cells for a 960px camera instead of 2400.
    - Skipped hidden/disconnected updates and redundant static-camera writes.
  Bugfixes:
    - Removed cameras safely when their surface is deleted; cancelled unfinished gestures on reconnect.
    - Accepted both standard Factorio map-position forms in the remote interface.

Version: 0.6.0
Date: 2026-09-05
  Features:
    - Left-click with placeable items, cursor ghosts or blueprints to request robot construction in cameras.

    - Construction works across surfaces without moving the player or consuming held materials.
  Notes:
    - Click-by-click placement only; no native building preview or area drag inside cameras.
    - Physical reach checks remain in place for machine inventory interaction.
