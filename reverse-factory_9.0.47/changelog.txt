  Info:
    - Updated to Factorio v2.0. Compatible with or without Space Age dlc.
    - Removed previous migration scripts, they were breaking things. Probably unnecessary.
  Changes:
    - Recycling efficiency algorithm has been updated to be similar to space age scrap recycler.
      Default efficiency is 25% to match, but can be modified just as before.
      See FAQ's on mod portal for more information as to how the changes impact gameplay.
    - Fluids recycle as items setting is no longer in beta, and now fully implemented.

      Icons use modified versions of the space age ice cube, even in vanilla. (no mod fluids yet)

      This setting caused more annoyances than it probably prevented.
    - Maximum tiers have been reduced to 3 (since 4 was unnecessary). Various numbers have been
      tweaked to re-balance the remaining tiers, so the new t3 should feel similar to the old t4.
    - Tier 1 can recycle all items without fluid ingredients or allowed productivity
      Tier 2 can recycle all items without allowed productivity
      Tier 3 can recycle all items without limitations
    - Modules now fast transfer into module slots only, requires intentional placing to recycle.
      This functionality is identical to the vanilla scrap recycler
  Graphics:
    - Tweaked the image brightness of the t2 Reverse Factory, so all 3 tiers look a bit different.
  Bugfixes:
    - Fixed all unknown key issues, due to vanilla Factoripedia displaying the names of all items.

Version: 5.1.0
  Info:
    - Massive rewrite of core mod
  Major Features:
    - Recyclers come in 2 tiers; t1 produces solids, t2 produces solids and fluids
    - Recycler icons now use powerbars, edited from Zombiee's ShinyBobGFX mod
    - T1 recycler is easier to research, requiring only red science, electronics and automation
    - T1 recipe requires more resources and is marginally slower, but retains its 2 module slots
    - T2 recycler is harder to craft and research, requiring steel, red circuits, 2 t2 assemblers
    - T2 recycler is almost twice as fast as before, with 4 module slots
    - Recyclers adhere to new normal/expensive mode, dynamically changing reverse recipes accordingly
    - Recyclers require alloy processing from bobs mods if detected (bronze for t1, invar for t2)
    - Recyclers output slots will stretch to fill the largest ingrediant amount in the game
  Minor Features:
    - Added new safety toggle, which prevents the recycling of dense recipes
  Changes:
    - Removed redundant settings, implemented into core mod
    - Automatic Ingredient push setting still exists and works with new tier of recycler
